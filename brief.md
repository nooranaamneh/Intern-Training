# Project Title: 
                 Task Manager



# Description:  
                A web-based task management system that allows users to create, update, and track tasks. Each task has a title, deadline, and 

                status, and can be assigned to a specific user. The system supports role-based access, distinguishing between administrators who 

                manage all tasks and users, and regular users who manage tasks assigned to them.



# Target Users: 
                 Admin — manages all users and all tasks, has full CRUD access across the system.

                 Regular User — views and updates tasks assigned to them.



# Feature List: 
                - Full CRUD operations on Tasks (Create, Read, Update, Delete)

                - Filter tasks by status (To-Do / In-Progress / Done)

                - Assign tasks to specific users

                - REST API endpoints for task operations

                - Role-based access control (Admin vs. User)

                - User authentication via Spring Security
